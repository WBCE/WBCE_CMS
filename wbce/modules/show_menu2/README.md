# show_menu2, version 4.16.0
## introducing `show_menu()` function alias.
---
> **Note:** As of this version, `show_menu()` is a plain alias for `show_menu2()` with an identical signature. Both names can be used interchangeably; `show_menu()` is just the shorter spelling.

Matching this, every `SM_*` constant (`SM_ROOT`, `SM_TRIM`, etc.) automatically has an equivalent `SM2_*` variant—both prefixes are interchangeable, e.g., `SM_TRIM|SM_USE_ARIA == SM2_TRIM|SM2_USE_ARIA`.

> In this README we will use show_menu() thoughout the document.
---
## About show_menu()

It is a template function for WBCE CMS that enables you to generate all kinds of menu styles. 
All menu data is retrieved using a single database query, and all types of menu styles (lists, breadcrumbs, sitemaps) can be generated with extensive customization of the resulting HTML.

---


## Using `show_menu()` 

You need to modify the PHP files of your template to call `show_menu()` where you wish to have the menu displayed. Remember when you replace calls to old menu functions to use the new parameters that `show_menu()` requires. 



## Styling
In some cases, the default menu generated by `show_menu()` is all that you need. This menu shows the current page and children of the current page. It is generated by calling `show_menu()` with no parameters:

```php
show_menu();
```

Note that the call to `show_menu()` is PHP, so you usually need to wrap it in PHP code tags so that it will execute:

```php
<?php show_menu(); ?>
```

This default menu generates a complete list-based menu with many classes that allow CSS styling. For example, the current menu item will have the `menu-current` class added to the `<li>` tag. Additionally, every menu item with a sub-menu will have the `menu-expand` class added to the `<li>` tag. This allows you to create CSS rules to style those menu items differently:

```css
li.menu-expand  { font-weight: bold; }
li.menu-current { background: red; }
```

See the [HTML Output](#html-output) section for details of exactly what classes are added to each element. More elaborate and different menu structures can be created by supplying different parameters to the `show_menu()` function call. 

For example, to show only menu items from the top level of the menu, use:

```php
show_menu(0, SM_ROOT, SM_START);
```

Alternatively, to show up to two levels of the child menus of the current page:

```php
show_menu(0, SM_CURR+1, SM_CURR+2);
```

There are many more possible menus that can be generated by `show_menu()`. See the demonstration website at [https://sm2.wbce-cms.org/](https://sm2.wbce-cms.org/) for more examples.

## Common Questions

**Q: How do I create a drop-down menu?**  
A: This is not directly related to `show_menu()`. Basically, you need to change the template CSS code to display the menu as a drop-down.

**Q: Why does the menu disappear after I do a search on my multilingual site?**  
A: You're missing some required lines in your template:
1. Log into administration, go to **Settings -> Show advanced settings -> Search Settings -> Header Code**, and add the following input field after the `<form>` open tag:
   ```html
   <input type="hidden" name="referrer" value="[REFERRER_ID]" />
   ```
2. In the `index.php` of your template, add the following input field immediately following the search `<form>` open tag:
   ```php
   <input type="hidden" name="referrer" value="<?php echo defined('REFERRER_ID')?REFERRER_ID:PAGE_ID;?>" />
   ```

**Q: Multilingual? That sounds cool. How do I do that?**  
A: See [https://addons.wbce.org/pages/addons.php?do=item&item=3](https://addons.wbce.org/pages/addons.php?do=item&item=3).

**Q: `show_menu()` is generating a warning every time the page is accessed: `"show_menu error: $aOptions is invalid. No flags from group 1 supplied!"`**  
A: You are passing the wrong values to the function. Have a closer look at the parameters that you are passing. See the [Parameters](#parameters) section below for the correct flag values to pass for the `$aOptions` parameter.

**Q: How do I use a different class/picture/color/widget for each entry in a menu?**  
A: Use the `[page_id]` format string in the `$aItemOpen` string. Create a unique class or ID for each menu item, then reference that item in your CSS or JavaScript to do whatever you want.

*To add a unique class for each menu item (or similar):*
```php
"<li><a href="[url]" target="[target]" class="[class] p[page_id]">[menu_title]</a>"
```
*Creating menu items like:*
```html
<li><a href="/pages/foo/bar.php" target="_top" class="menu-top p45">Top Menu</a>
```
*Reference this in your CSS like:*
```css
a.p45 { color: red; }
```

*To add a unique ID for each menu item (or similar):*
```php
"<li><a id="p[page_id]" href="[url]" target="[target]" class="[class]">[menu_title]</a>"
```
*Creating menu items like:*
```html
<li><a id="p45" href="/pages/foo/bar.php" target="_top" class="menu-top">Top Menu</a>
```
*Reference this in your CSS like:*
```css
a#p45 { color: red; }
```
> **Note:** The ID can only be used if that menu is generated and displayed **one time only** on the page (because HTML IDs must be unique within a page).

## Function

The complete call signature and default parameter values for `show_menu()` are:

```php
show_menu(
    $aMenu         = 0,
    $aStart        = SM_ROOT,
    $aMaxLevel     = SM_CURR+1,
    $aOptions      = SM_TRIM,
    $aItemOpen     = '[li][a][menu_title]</a>',
    $aItemClose    = '</li>',
    $aMenuOpen     = '[ul]',
    $aMenuClose    = '</ul>',
    $aTopItemOpen  = false,
    $aTopMenuOpen  = false
)
```

See the [Parameters](#parameters) section for detailed descriptions of each parameter. Ensure that you use each parameter correctly:
* `$aMenu` will be `0` for most people.
* `$aStart` must be either a page ID or a value starting with `SM_`.
* `$aMaxLevel` must be only values that start with `SM_`.
* `$aOptions` must be only values that start with `SM_` (unless you are in a very small minority of users).
* All other parameters are the HTML tag templates that will be output for menus and menu items.

> **Note:** Every parameter from `$aItemOpen` onwards can be supplied as `false` to use its default value.

## HTML Output

The menu is output differently depending on what parameters have been supplied to the function. However, in general, the following classes are used for each menu. Note that items will have multiple classes when relevant.

| Class          | Attached To                                |
| -------------- | ------------------------------------------ |
| `menu-top`     | First menu tag only                        |
| `menu-parent`  | Every parent menu item of the current page |
| `menu-current` | Only the menu item for the current page    |
| `menu-sibling` | Every sibling of the current page          |
| `menu-child`   | Every sub-menu of the current page         |
| `menu-expand`  | Every menu item with children              |
| `menu-first`   | First item in any menu or sub-menu         |
| `menu-last`    | Last item in any menu or sub-menu          |

The following classes are added only if the `SM_NUMCLASS` flag has been used:

| Class          | Attached To                                                                                                                                                              |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `menu-N`       | Every menu item. `N` is replaced with the **absolute** menu depth of the item starting with 0. The root level menu is always `menu-0`, the next level is `menu-1`, etc. |
| `menu-child-N` | Every sub-menu of the current page. `N` is replaced with the relative depth of the submenu starting at 0.                                                                |

### Structure Example

```html
<ul class="menu-top menu-0">
  <li class="menu-0 menu-first">  ... </li>
  <li class="menu-0 menu-expand menu-parent">  ...
  <ul class="menu-1">
    <li class="menu-1 menu-expand menu-first">  ...
    <ul class="menu-2">
      <li class="menu-2 menu-first">  ...
      <li class="menu-2 menu-last">  ...
    </ul>
    </li>
    <li class="menu-1 menu-expand menu-parent">  ...
    <ul class="menu-2">
      <li class="menu-2 menu-expand menu-current menu-first">  ...      <!-- CURRENT PAGE -->
      <ul class="menu-3">
        <li class="menu-3 menu-child menu-child-0 menu-first">  ...
        <ul class="menu-4">
          <li class="menu-4 menu-child menu-child-1 menu-first">  ... </li>
          <li class="menu-4 menu-child menu-child-1 menu-last">  ... </li>
        </ul>
        </li>
        <li class="menu-3 menu-child menu-child-0 menu-last">  ... </li>
      </ul>
      </li>
      <li class="menu-2 menu-sibling menu-last">  ... </li>
    </ul>
    </li>
    <li class="menu-1">  ... </li>
    <li class="menu-1 menu-expand menu-last">  ...
    <ul class="menu-2">
      <li class="menu-2 menu-first menu-last">  ... </li>
    </ul>
    </li>
  </ul>
  </li>
  <li class="menu-0 menu-last">  ... </li>
</ul>
```

## Parameters

### `$aMenu`
Menu number to use. This is useful when you are using multiple menus. Supplying a menu number of `0` will use the default menu for the current page. Supplying `SM_ALLMENU` will return all menus in the system.

### `$aStart`
Specify where the menu generation should start from. This is usually the parent item of the menu to display. It must be one of the following values:

* `SM_ROOT+N`: Start `N` levels down from the root:
  * `SM_ROOT`: Starting at the root menu
  * `SM_ROOT+1`: Start 1 level below the root
  * `SM_ROOT+2`: Start 2 levels below the root
* `SM_CURR+N`: Start `N` levels down from the current page level:
  * `SM_CURR`: Starts at the current page level (all sibling menus to the current page)
  * `SM_CURR+1`: Starts 1 level down from the current page with the children menus
* `page_id`: Display using the specific page as the parent. All child menus of that page will be displayed. The `page_id` can be found by editing the page in the WB admin interface (included in the URL like `http://SITE/admin/pages/modify.php?page_id=35`).

### `$aMaxLevel`
Maximum menu level to display. Menus are displayed from the start level down to this level:

* `SM_ALL`: No limit, all levels are displayed.
* `SM_CURR+N`: Always show to the current page + `N` levels:
  * `SM_CURR`: Current level (no children)
  * `SM_CURR+3`: All parents + current + 3 children levels
* `SM_START+N`: Always show from the starting level + `N` levels regardless of what level the current page is on:
  * `SM_START`: Single level of menus from starting level
  * `SM_START+1`: Starting level and 1 level down
* `SM_MAX+N`: Show at most `N` levels from the starting level. Levels won't be shown if they are below the current level:
  * `SM_MAX`: Starting level only (same as `SM_START`)
  * `SM_MAX+1`: Maximum of starting level and 1 level down

### `$aOptions`
Specify flags for different generation options for the menu. Flags may be combined together using bitwise OR (`|`). For example: `(SM_TRIM | SM_PRETTY)`.

#### Group 1 (Required)
**Exactly one flag from this group must always be supplied.** These flags affect how siblings in the tree are removed from the output:

* `SM_ALL`: Show all branches of the menu tree.
  ```text
  A-1 -> B-1 
      -> B-2 -> C-1
             -> C-2 (CURRENT)
                -> D-1
                -> D-2
             -> C-3
  A-2 -> B-3
      -> B-4
  ```
* `SM_TRIM`: Show all sibling menus of pages on the current path. All sub-menus of elements that are not on the path are removed.
  ```text
  A-1 -> B-1 
      -> B-2 -> C-1
             -> C-2 (CURRENT)
                -> D-1
                -> D-2
             -> C-3
  A-2 
  ```
* `SM_CRUMB`: Show only the breadcrumb trail (the current menu and all of its ancestor menus).
  ```text
  A-1 -> B-2 -> C-2 (CURRENT)
  ```
* `SM_SIBLING`: Same as `SM_TRIM`, however only sibling menus of the current page are displayed. All other menus are trimmed to show only the path.
  ```text
  A-1 -> B-2 -> C-1
             -> C-2 (CURRENT)
                -> D-1
                -> D-2
             -> C-3
  ```

#### Group 2 (Optional)
Any number of these optional flags may be combined:

* `SM_NUMCLASS`: Add numbered menu classes (`menu-N` and `menu-child-N`).
* `SM_ALLINFO`: Load all fields from the page table of the database. Useful for making keywords, descriptions, and other fields available, though it uses more memory.  
  > **Note:** Must be used on the *first* call to `show_menu()` for this menu ID, or in combination with `SM_NOCACHE`; otherwise, it will have no effect.
* `SM_NOCACHE`: Do not reuse or store data read from the database between calls to `show_menu()`.
* `SM_PRETTY`: Pretty-print the menu HTML with spacing and newlines for debugging purposes.
* `SM_BUFFER`: Do not output HTML directly; buffer it internally and return it as a string from `show_menu()`.
* `SM_CURRTREE`: Exclude all other top-level menus from being considered. Only items in the current menu tree will be output. Can be combined with Group 1 flags.
* `SM_ESCAPE`: Call `htmlspecialchars` on menu strings. Permits menus to have HTML formatting safely without failing validation.
* `SM_SHOWHIDDEN`: Enables hidden pages to become visible when they are active (current page or parent page).
* `SM_XHTML_STRICT`: Removes the `target` attribute from all links created by `[a]` or `[ac]` to preserve XHTML compatibility.
* `SM_NO_TITLE`: Suppresses the value of `title` attributes on links created by `[a]` or `[ac]`.
* `SM_EXTERNAL_MENULINKS`: For `menu_link` items, resolves external target URLs directly when configured with "External" link type, bypassing the redirect hop. Internal targets are always resolved automatically. Pure structure nodes (`Structure Only, no link`) get `href="#"`.
* `SM_USE_ARIA`: Populates the `[aria]` placeholder with ARIA attributes for screen readers (`aria-current="page"`, `aria-haspopup="true"`, `aria-expanded="true/false"`). Automatically inserted for built-in `[a]` and `[ac]` tags.

> The `$aOptions` parameter also accepts an associative array for extended usage. See [Extended Options](#extended-options).

### `$aItemOpen`
Format string to use for creating each individual menu item entry. A different format string may be used for the very first entry by supplying `$aTopItemOpen`. When set to `false`, it uses the default of `'[li][a][menu_title]</a>'`. 

For easier CSS styling applied directly to the link, use: `'<li>[ac][menu_title]</a>'`.

May also be specified as an instance of a formatting class (see [Formatter](#formatter)). When a custom formatter is supplied, all arguments after `$aItemOpen` are ignored.

### `$aItemClose`
String used to close each item (default: `'</li>'`). Plain string; keywords are not replaced.

### `$aMenuOpen`
Format string to use for opening a list of menu item entries (default: `'[ul]'`). A different format string may be used for the very first menu using `$aTopMenuOpen`.

### `$aMenuClose`
String used to close each menu (default: `'</ul>'`). Plain string; keywords are not replaced.

### `$aTopItemOpen`
Format string for the first item. When set to `false`, it uses the same format as `$aItemOpen`.

### `$aTopMenuOpen`
Format string for the first menu. When set to `false`, it uses the same format as `$aMenuOpen`.

## Extended Options

To access extended options, pass `$aOptions` as an associative array (the `SM_*` flags are still required under the `'flags'` key):

* `'flags'` (**REQUIRED**): Flags described in the [Parameters](#parameters) section.
* `'notrim'`: Number of levels relative to `$aStart` that will always be displayed, overriding `SM_TRIM` for those levels.

```php
$options = array('flags' => (SM_TRIM | SM_PRETTY), 'notrim' => 1);
show_menu(0, SM_ROOT, SM_CURR+1, $options);
```

## Format Strings

The following tags can be used in `$aItemOpen` and `$aMenuOpen` format strings:

| Tag            | Replacement                                                                    |
| -------------- | ------------------------------------------------------------------------------ |
| `[a]`          | `<a>` tag without class: `<a href="[url]" target="[target]">`                  |
| `[ac]`         | `<a>` tag with class: `<a href="[url]" target="[target]" class="[class]">`     |
| `[li]`         | `<li>` tag with class: `<li class="[class]">`                                  |
| `[ul]`         | `<ul>` tag with class: `<ul class="[class]">`                                  |
| `[class]`      | Space-separated list of CSS classes for that page                              |
| `[menu_title]` | Menu title text (HTML entity escaped unless `SM_NOESCAPE` is used)             |
| `[menu_icon_0]`| Image URL for normal status                                                    |
| `[menu_icon_1]`| Image URL for active/hover status                                              |
| `[page_title]` | Page title text                                                                |
| `[page_icon]`  | Image URL for current page icon                                                |
| `[url]`        | Page URL                                                                       |
| `[target]`     | Page target attribute                                                          |
| `[page_id]`    | Page ID of current item                                                        |
| `[parent]`     | Page ID of parent item                                                         |
| `[level]`      | Page depth level (matches `menu-N` CSS tag)                                    |
| `[sib]`        | Current menu sibling index                                                     |
| `[sibCount]`   | Total number of siblings in this menu                                          |
| `[aria]`       | ARIA attributes (populated when `SM_USE_ARIA` flag is active)                  |
| `[if]`         | Conditional directive (see [Conditional Formatting](#conditional-formatting))  |

### Available with `SM_ALLINFO` Flag

| Tag             | Replacement           |
| --------------- | --------------------- |
| `[description]` | Page meta description |
| `[keywords]`    | Page meta keywords    |

## Conditional Formatting

Conditional directives take one of two forms:

```text
[if(A){B}]
[if(A){B}else{C}]
```

* **A**: Conditional test expression.
* **B**: Expression emitted when the test is **true** (must NOT contain `}`).
* **C**: Expression emitted when the test is **false** (must NOT contain `}`).

Multiple tests can be combined using `||` (OR) or `&&` (AND).

### Left Operands

* `class`: Test for class presence (only `==` and `!=` allowed, meaning "contains" and "does not contain").
* `level`: Test against page level.
* `sib`: Test against sibling index.
* `sibCount`: Test against total sibling count.
* `id`: Test against page ID.
* `target`: Test against target attribute.

### Operators

`<`, `<=`, `==`, `!=`, `>=`, `>`

### Right Operands

* For `class`: Any `menu-*` class name.
* For `level`: `<number>`, `root`, `granny`, `parent`, `current`, `child`.
* For `id`: `<number>`, `parent`, `current`.
* For `sib`: A positive integer or `sibCount`.
* For `sibCount`: A positive integer.
* For `target`: A target string (e.g., `_self`, `_blank`).

### Examples

```text
[if(class==menu-expand){exp}]            Item has a sub-menu
[if(class==menu-first){exp}]             Item is first in menu
[if(class!=menu-first){exp}]             Item is NOT first in menu
[if(class==menu-last){exp}]              Item is last in menu
[if(level==0){exp}]                      Item is at root
[if(level>0){exp}]                       Item is not at root
[if(sib==2){exp}]                        Item is second in menu
[if(sibCount>1){exp}]                    Menu has more than 1 entry
[if(sibCount!=2){exp}]                   Menu does not have exactly 2 entries
[if(level>parent){exp}]                  Item is in a sibling menu or child of a sibling
[if(id==parent){exp}]                    Item is parent of current page
[if(target==_self){exp}]                 Target attribute is '_self'
[if(sib==2){exp}else{foo}]               Item is NOT second in menu
[if(sibCount>2){exp}else{foo}]           Menu does NOT have more than 2 entries
[if(sib == 1 || sib > 3){exp}]           Item is 1st OR 4th+ in menu
[if(id == current && class == menu-expand){exp}]  Item is current AND has children
```

> **Note:** Tests are evaluated left-to-right without short-circuiting or parenthetical grouping. `||` and `&&` share equal precedence.

## Formatter

> **Note:** Advanced feature!

You can replace the default menu formatter with a custom class module. See `include.php` in the module directory for implementation details. The custom class must expose the following interface:

```php
class SM_Formatter
{
    // Called once before processing to initialize object state
    function initialize() { }
    
    // Called to open the menu list
    function startList($aPage, $aUrl) { }
    
    // Called to open a menu item
    function startItem($aPage, $aUrl, $aCurrSib, $aSibCount) { }
    
    // Called to close a menu item
    function finishItem() { }
    
    // Called to close the menu list
    function finishList() { }
    
    // Called once after all menus have been processed
    function finalize() { }
    
    // Called after finalize() if SM_BUFFER flag is used
    function getOutput() { }
};
```
